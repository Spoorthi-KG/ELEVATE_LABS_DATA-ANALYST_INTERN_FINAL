# HR Analytics – Predict Employee Attrition

## 📘 Project Overview
This project analyzes HR data to identify key drivers of employee attrition and predicts which employees are most likely to leave using machine learning models.

## 🎯 Objective
To predict employee attrition and derive actionable insights that help HR departments improve retention.

## 🧰 Tools Used
- Python (Pandas, Scikit-learn, SHAP)
- Power BI (Dashboard)
- Matplotlib / Seaborn for Visualization

## 📊 Key Steps
1. Data Cleaning & Preprocessing  
2. Exploratory Data Analysis (EDA)  
3. Feature Engineering  
4. Model Training (Logistic Regression, Random Forest)  
5. Model Evaluation & Explainability (SHAP)  
6. Dashboard Creation in Power BI  

## 🧠 Results
- Model Accuracy: ~86%
- Top Attrition Factors: OverTime, JobSatisfaction, MonthlyIncome, Age
- Recommendations: Improve salary structure, reduce overtime, enhance employee engagement.
